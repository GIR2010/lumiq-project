# План 1 — ручная проверка в браузере (Task 14)

Отметьте каждый пункт ✅ / ❌ и допишите заметку. Найденный дефект — короткое описание: сайт, что видно, что ожидалось.

## Подготовка

1. В папке проекта выполнить `npm install` (если ещё не) и `npm run build`.
2. Открыть `chrome://extensions`, включить «Режим разработчика».
3. «Загрузить распакованное» → выбрать папку `dist`.
4. После каждой пересборки нажимать кнопку ↻ у расширения на `chrome://extensions`.

## Системная тема

|---|---|---|---|

## Что посмотреть в консоли (необязательно)

- DevTools страницы → Console, фильтр `[DarkExt]`: ошибок быть не должно.
- Консоль service worker: предупреждения вида «message port closed» при каждой смене настроек (проверка M12).
