# Этап 1.5а: ручная приёмка контраста

**Критерий:** на каждом сайте число нечитаемых элементов (контраст < 3), которое показывает `tools/contrast-scan.js`, снижается не менее чем на 90 % относительно базовой линии. Для сайтов, где важны иконки-картинки (rutracker, Переводчик, Wikipedia), проверка проводится после слияния планов 1.5а и 1.5б.

## Как снять базовую линию (сборка master)

1. `git worktree add ../chrome-plugins-master master` (или `git stash`/чистая копия), в ней `npm ci` и `npm run build`.
2. `chrome://extensions` → режим разработчика → «Загрузить распакованное» → папка `dist` этой сборки. Остальные копии расширения отключить.
3. Открыть сайт из таблицы, дождаться окончания работы расширения (около 5 секунд, страницу не трогать).
4. Открыть консоль страницы (F12), вставить содержимое `tools/contrast-scan.js` целиком и нажать Enter. Скрипт возвращает объект `{ own, groups, elements, top }`: `groups` и `elements` — числа для таблицы; `top` — до 12 крупнейших групп с цветами и правилами (текст страницы не включается). Допустимо вместо консоли запускать скрипт через `javascript_tool` Claude in Chrome.
5. Записать `groups` / `elements` в колонку «Базовая линия».

## Как снять результат (сборка этой ветки)

1. В ветке `feat/stage-1.5a-colors` (после слияния с 1.5б для rutracker, Переводчика, Wikipedia): `npm run build`.
2. В `chrome://extensions` отключить сборку master, загрузить распакованное расширение из `dist` этой ветки (или нажать «Обновить» у уже загруженного).
3. Повторить шаги 3-4 на тех же страницах, в том же состоянии (тот же вход в аккаунт, та же прокрутка и размер окна).
4. Записать `groups` / `elements` в колонку «После» и посчитать снижение.

## Что смотреть глазами

- Насыщенные фоны (круги аватаров, оранжевая плашка пагинации) остаются яркими, а текст на них читаем.
- Плашки «answers» (Stack Overflow) и рамки читаемы на тёмном фоне.
- Иконки через `mask-image` и инлайн-цепочки `--x-color: var(--…)` светлые.
- Скрытые `::-webkit-scrollbar` строки без лишней полосы прокрутки.

## Известное ограничение (план 2)

Белый текст на насыщенном светлом фоне (оранжевая плашка пагинации, #f48225) после правила 3.11 (светлота фона ограничивается 0.65) имеет контраст около 3.4; у исходного сайта около 2.9. Защита контраста пары «текст/фон» отложена на план 2, e2e проверяет порог 3.0.
